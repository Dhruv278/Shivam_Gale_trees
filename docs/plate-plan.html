4. Future phases (after the prototype is approved)

Phase 1 — Per-tree data model

You drop the tree photos into one agreed folder (species sub-folders, e.g. public/images/Aam/Aam 1.jpg) — the build picks them up from that folder automatically and matches every file to its Excel row. Manifest is built from the Excel + that folder. Viewer becomes per-tree (/view/aam-1). 1,777 static pages — still a fully static site, well within Cloudflare Pages limits. Slug-lock rules unchanged, so a printed QR can never point to the wrong tree. Photos added later are picked up on the next build with no code change.

Phase 2 — Bulk QR generation

The existing "Generate QR Codes" panel automatically scales to 1,777 once the manifest is per-tree. The ZIP gains species folders matching the Excel.

Phase 3 — Bulk plate generation

45 template images + per-species config (QR box position, number position, fonts). Two ways to generate:

  • In the portal — download a single plate, or one species' full batch (largest is Ashok: 323 plates — fine in a browser).
  • Production script — one command generates all 1,777 plate JPGs to disk in species folders. More reliable than holding a ~500 MB ZIP in browser memory. This is what you run for the final print files.
Phase 4 — Verification before printing

Automated checks, because printed metal cannot be patched:

  • Every Excel row has a matching photo file (report every missing/extra photo)
  • Every generated QR is decoded back and must equal its exact viewer URL (test already exists for the 45; it scales up)
  • Every plate JPG exists, correct count per species folder

5. What we need from you (nothing prints without these)

Your inputs
  • Final Excel — the tree list is the ID source (species + number)
  • 1,700+ tree photos, named/foldered to match the Excel (Aam 1.jpg, Aam 2.jpg…)
  • 45 clean high-resolution template plates from the designer (one per species, Hindi name baked in) — not WhatsApp copies, WhatsApp compresses images and print will show it
  • Fonts — the number font (and Hindi font if anything textual is stamped by code)
  • Plate physical size (cm) so the JPG resolution matches print quality
  • Final domain locked — every QR embeds the site URL permanently; changing the domain after printing invalidates all 1,777 plates
